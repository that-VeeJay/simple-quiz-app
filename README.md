# 🧠Simple Quiz App

This is a responsive quiz application built with React that allows users to select a category, answer multiple-choice questions, and view their score upon completion. It features dynamic question sets, instant feedback, and a restart option to retake quizzes.

## ✨Features

- Category selection
- Dynamic question sets with multiple-choice options
- Real-time score calculation and result display
- Option to review correct and user-submitted answers
- Ability to restart the quiz from the result screen
- Fully responsive design for all screen sizes

## 🚀Installation and Setup

Follow these steps to get the project up and running locally:

1. Clone the repository

```bash
git clone https://github.com/your-username/your-repo-name.git
```

2. Navigate into the project directory

```bash
cd your-repo-name
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

The app will usually be available at **http://localhost:5173** by default (if you're using [Vite](https://vite.dev/)). Check your terminal output for the exact URL.

## 🧪 Usage & Learning Purpose

This project was created as a learning exercise to reinforce and deepen my understanding of React fundamentals. It serves as a reference for:

- Component structure and reuse
- State management using hooks (useState)
- Conditional rendering and event handling
- Styling with Tailwind CSS
- Routing with react-router-dom

Inspired by [Pedro Tech's](https://youtu.be/3OqiKTyH4r0) React tutorial, I expanded the project with additional features and personal touches to explore customization and improve user experience.

The goal was to not only replicate core concepts but also to explore customization, optimization, and best practices in modern front-end development.
